# AI Code Reviewer

An AI-powered code review application that analyzes JavaScript code and provides useful feedback using Google Gemini API.

## 🚀 Live Demo

[🔗 Open AI Code Reviewer](https://ai-code-reviewer-frontend-wc10.onrender.com)

## ✨ Features

- Write and edit JavaScript code
- AI-powered code review
- Detect bugs and errors
- Code quality suggestions
- Improved/corrected code
- Developer tips
- Syntax highlighting
- Responsive UI

## 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- Axios
- Prism.js
- React Markdown

### Backend

- Node.js
- Express.js
- Google Gemini API
- CORS

## ⚙️ How It Works

1. User enters JavaScript code.
2. Frontend sends the code to the Express backend.
3. Backend sends the code to Google Gemini.
4. Gemini analyzes the code.
5. AI-generated review is returned to the frontend.
6. The review is displayed in the frontend.

## 🔐 Environment Variables

The Gemini API key is stored securely using environment variables.
